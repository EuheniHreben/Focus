# ✅ FOCUS — ToDo App (Vanilla JavaScript)

A clean and modern ToDo application built with pure HTML, CSS, and JavaScript.  
Designed with smooth animations, customizable settings, and persistent local storage—no frameworks or backend required.

---

## ✨ Features

### 📋 Task Management

- Add new tasks
- Prevent empty and duplicate tasks
- Mark tasks as completed
- Remove individual tasks
- Clear all completed tasks
- Automatic sorting of completed tasks
- Built-in onboarding task list on first launch

### ⚙️ Customization

- Light theme
- Dark theme
- Automatic theme based on time of day
- Follow system theme
- Sort by creation date
- Sort alphabetically
- Adjustable font size
- Text alignment (Left / Center)
- Sound on/off

### 🎨 User Experience

- Modern glassmorphism interface
- Smooth animations and transitions
- Responsive design
- Toast notifications
- Animated settings panel
- Heroicons SVG icons
- Mobile vibration feedback
- Sound effects when completing tasks

### 💾 Data Persistence

- Tasks are stored in `localStorage`
- User preferences are stored separately
- Works completely offline

### 📤 Extras

- Copy the entire task list to the clipboard
- First-run tutorial tasks
- Empty state message
- Input validation with visual feedback
